# 방울토마토 양액재배 스마트팜 — 프로토타입 계산 검증

비닐하우스 방울토마토 양액재배 스마트팜 시스템의 DB 설계와 계산 로직이 맞는지, 실제 센서 없이 **예시 데이터**로 확인하는 프로토타입입니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `sql/schema_sqlite.sql` | 테이블 10개 스키마 (검증에 필요한 테이블만, SQLite) |
| `sql/daily_summary.sql` | 일별 요약(daily_summary) 집계 쿼리 |
| `verify.py` | 예시 데이터 생성, 경고 생성·해제 로직, 테스트 케이스 실행 |
| `expected_output.json` | 실행 결과 (2026-11-05 기준) |

설계상 테이블은 12개이며, 이 검증에서는 `zone`, `note`를 제외한 10개를 사용합니다. 설계 DBMS는 MySQL이지만 검증 환경에 MySQL 서버가 없어 같은 구조를 SQLite로 만들었습니다.

## 실행

Python 3.9 이상, 표준 라이브러리만 사용합니다.

```bash
python3 verify.py
```

메모리 DB(`:memory:`)를 쓰므로 파일이 생기지 않으며, 결과는 JSON으로 출력됩니다.

## 예시 데이터

- 작기: 정식일 2026-08-10, 500포기, 위탁수수료 7%, 부대비용 400원/kg, 10-01부터 수확기
- 환경: 11-05 00:00~15:30, 1분 간격. 03:00 9.8℃ 급랭, 13:10~15:05 28℃ 초과(최고 29.6℃)
- 급액: 11-03 600 L, 11-04 640 L, 11-05 412 L (10:36 1회 EC 2.6)
- 배액: 11-05 합계 99 L
- 수확(11-02~11-05): 상품 171 kg, 비상품 15 kg / 시장가 4,850원/kg / 정산 단가 4,300원/kg

낮은 06:00~17:59, 그 외는 밤으로 봅니다.

## 경고 로직

- 측정값이 기준을 벗어나면 경고 1건을 열고, 이탈이 이어지는 동안에는 최고값만 갱신합니다.
- 적정 범위 이탈은 `caution`, 경고 기준 초과는 `warning`입니다.
- 해제는 여유값을 둡니다 (온도 0.5℃, EC 0.05).

## 결과 요약

15건 중 14건이 기대값과 일치했습니다.

| 항목 | 결과 |
| --- | --- |
| 하루 급액량 / 포기당 | 412 L / 0.824 L |
| 배액률 | 24.03% |
| 작기 누적 급액량 | 1,652 L |
| 낮 고온 경고 | 13:10 시작, 최고 29.6℃, 15:05 해제 (28℃ 초과 107분 동안 1건) |
| 밤 저온 경고 | 03:00 warning, 03:01 해제 |
| 이번 주 예상 입금액 | 702,896원 |
| 실제 입금액 | 735,300원 |

**발견 사항(TC-15):** 06:00 낮 기준(21~28℃)으로 바뀌는 순간 온도가 14.6℃라 '낮 저온 주의' 경고가 06:00~08:40 이어졌습니다. 해 뜬 뒤 온도가 오르는 정상 과정이므로, 아침 시간대 기준을 따로 두는 개선이 필요합니다.
