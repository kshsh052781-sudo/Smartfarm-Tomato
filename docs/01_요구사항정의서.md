# 요구사항 정의서

방울토마토 양액재배 비닐하우스(1동, 500포기 가정) 스마트팜 시스템의 요구사항이다.

## 1. 수집 데이터와 주기

| 구분 | 항목 | 주기 | 용도 |
| --- | --- | --- | --- |
| 센서 | 온도 | 1분 | 낮·밤 관리, 고온·저온 경고 |
| 센서 | 습도 | 1분 | 결로·병해 위험 판단 |
| 센서 | 일사량 | 1분 | 누적 일사량, 급액 시점 참고 |
| 센서 | CO₂ | 1~5분 | 대시보드 표시 전용 |
| 양액기 | 급액량, 급액 EC·pH | 급액할 때마다 | 하루·누적 급액량, 양액 농도 확인 |
| 센서 | 배액량, 배액 EC | 배액될 때마다 | 배액률, 배지 염류 상태 |
| 사람 | 작기 정보(품종, 정식일, 포기 수, 수수료율, 부대비용) | 작기 시작 시 | 계산 기준 |
| 사람 | 수확 기록(날짜, 구역, 등급, kg), 정산 단가 | 수확·정산 시 | 수확량, 입금액 |
| 사람 | 특이사항 메모 | 있을 때만 | 농약 살포, 병해충 기록 |
| 외부 | 방울토마토 경매 가격 (aT API) | 하루 1회 | 시장 평균가, 예상 입금액 |

## 2. 기능 요구사항

| 번호 | 요구사항 |
| --- | --- |
| FR-01 | 센서값을 1분마다 저장한다. |
| FR-02 | 급액·배액 발생 시 시각, 양, EC(급액은 pH 포함)를 저장한다. |
| FR-03 | 현재 생육 단계와 낮·밤에 맞는 기준을 찾아 측정값과 비교한다. |
| FR-04 | 기준 이탈 시 경고 1건을 생성하고 알림을 보낸다. 진행 중인 같은 경고가 있으면 최고값만 갱신한다. |
| FR-05 | 기준 안으로 복귀하면(해제 여유값 적용) 경고를 해제한다. |
| FR-06 | 농부가 알림을 확인하고 조치 메모를 남길 수 있다. |
| FR-07 | 매일 자정 배액률·포기당 급액량을 계산해 기준과 비교한다. |
| FR-08 | 매일 1회 aT API에서 방울토마토 경매 가격을 받아 저장한다. |
| FR-09 | 수확·정산 단가를 입력받아 예상·실제 입금액을 계산한다. |
| FR-10 | 대시보드에 현재 상태, 진행 중 경고, 양액, 오늘 추이, 수확·수익, 경고 이력을 보여준다. |

## 3. 비기능 요구사항

| 번호 | 요구사항 |
| --- | --- |
| NFR-01 | 대시보드의 현재 상태는 1분마다 갱신한다. |
| NFR-02 | 5분 넘게 센서 데이터가 들어오지 않으면 연결 끊김 경고를 보낸다. |
| NFR-03 | 긴급 경고는 메신저와 문자 두 채널로 보낸다. |
| NFR-04 | 휴대폰 화면 기준으로 설계하고 PC에서도 볼 수 있다. |
| NFR-05 | 모든 시각은 한국 시간(KST)으로 저장한다. |
