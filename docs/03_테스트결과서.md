# 테스트 결과서

방울토마토 양액재배 스마트팜 프로토타입의 계산 검증 결과다. 실행 코드는 `prototype/verify.py`에 있다.

## 1. 검증 방법

예시 데이터를 DB에 넣고, DB가 계산한 값이 손계산 기대값과 같은지 확인했다. 검증 환경에 MySQL 서버가 없어 같은 테이블 구조를 SQLite로 만들었고, 집계는 SQL로, 경고 생성·해제는 서버 로직을 Python으로 구현해 실행했다. 금액은 원 단위 반올림, 비율과 양은 소수 둘째 자리까지 비교했다.

## 2. 예시 데이터

| 항목 | 값 |
| --- | --- |
| 작기 | 정식일 2026-08-10, 500포기, 수수료율 7.00%, 부대비용 400원/kg |
| 생육 단계 | 2026-10-01부터 수확기 |
| 검증일 | 2026-11-05 (정식 후 87일) |
| 낮/밤 | 낮 06:00~17:59, 그 외 밤 |
| 환경 데이터 | 11-05 00:00~15:30, 1분 간격 931행. 03:00 한 번 9.8℃로 급랭, 13:10부터 28℃ 초과(최고 29.6℃), 15:05에 27.4℃로 하강 |
| 급액 | 11-03 600 L(20회), 11-04 640 L(16회), 11-05 412 L(30 L × 10회 + 28 L × 4회). 11-05 10:36 1회는 EC 2.6, 나머지 EC 2.2 |
| 배액 | 11-05 합계 99 L (11 L × 9회) |
| 수확(11-02~11-05) | 상품 171 kg, 비상품 15 kg |
| 시장 평균가 | 4,850원/kg (가락시장, 상 등급) |
| 정산 단가 | 4,300원/kg (실수령 기준) |

## 5. 발견 사항

아침 6시 낮 기준(21~28℃)으로 바뀌는 순간 실제 온도가 14.6℃라 '낮 온도 적정 범위 미만' 주의 경고가 06:00~08:40(2시간 40분) 이어졌다. 해 뜬 뒤 온도가 서서히 오르는 정상적인 과정인데 경고로 잡혀, 실제 운영에서는 매일 아침 불필요한 알림이 갈 수 있다. TC-15의 기대값 3건과 결과 4건의 차이도 이 경고 때문이며, 집계 자체는 정확했다.

| 개선안 | 방법 | 설계 반영 |
| --- | --- | --- |
| 전환 유예 | 낮 시작 후 일정 시간(예: 3시간) 동안 낮 하한 경고를 보내지 않음 | 경고 로직에 유예 시간 설정 추가 |
| 단계적 목표 | 아침 시간대 목표를 따로 둠(예: 06~09시 15~21℃) | cultivation_standard의 period에 morning 추가 |
